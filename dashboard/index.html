8-Sentence Stakeholder & Engineering Root-Cause Analysis

            

              1. What is happening: Returning users with an expired or revoked login token (jwt) in window.localStorage experience an immediate blank white screen on launch.
              2. Stakeholder impact: Because localStorage persists across browser restarts, affected users are permanently locked out of Conduit until they manually purge browser storage.
              3. Trigger: On startup, App.componentWillMount() attaches localStorage.getItem('jwt') to all outgoing requests before validating token freshness.
              4. Concurrent API call: Home/index.js dispatches HOME_PAGE_LOADED with Promise.all([agent.Tags.getAll(), articlesPromise]) carrying the stale token.
              5. Middleware flaw: When the API rejects with 401 Unauthorized, promiseMiddleware (src/middleware.js) sets action.error = true and replaces the expected [tags, articles] array with the raw error object.
              6. Reducer bug: src/reducers/home.js fails to check if (action.error) and evaluates action.payload[0].tags when action.payload[0] is undefined.
              7. Crash: JavaScript throws Uncaught TypeError: Cannot read property 'tags' of undefined, unmounting the React tree.
              8. Remediation: Intercept 401 in src/middleware.js to clear localStorage.jwt and guard src/reducers/home.js with if (action.error || !Array.isArray(action.payload)).

“Defend Every Choice” — Technical Interview Cheat Sheet

            
Exact engineering answers for the 30–45 minute follow-up conversation.

          


          

            

              
Q1: “Why did you pick the GitHub Search API + README API + HackerNews Algolia API in Task 2?”

              

                GitHub Search API gives quantitative repository metrics (stars, forks, open issues), but a repo title alone doesn't tell an engineering team what architecture it uses or whether real developers trust it. Enriching the Top 5 repos with both the decoded GitHub /readme endpoint and HackerNews Algolia community discussion points combines code documentation with external social proof—and requires zero paid API keys.
              

            

            

              
Q2: “Why did you use a JavaScript Code Node instead of pure n8n Set/Filter nodes?”

              

                A Code node lets us perform filtering (!repo.archived && repo.description), calculate a custom weighted velocity formula (stars + forks*2 + min(issues, 200)), sort descending, slice the Top 5, and decode Base64 README markdown in a single deterministic step rather than chaining 6 separate nodes.
              

            

            

              
Q3: “Why did you choose stars > 1000 as the IF threshold?”

              

                In open-source tooling, 1,000 stars separates battle-tested breakout projects (which merit immediate visibility in #eng-morning-brief) from early experimental repos (<= 1000 stars), which are routed to a Google Sheets watchlist so the team's Slack channel never suffers from alert fatigue.
              

            

            

              
Q4: “How does your workflow guarantee it never crashes silently?”

              

                We use defense-in-depth: (1) HTTP Request nodes configure retryOnFail: true (3 tries, 2000ms backoff) to survive transient network blips; (2) onError: continueErrorOutput routes HTTP 403/429/5xx errors to a dedicated Error Formatter & Slack Incident node; and (3) a workflow-level Global Error Trigger catches any unexpected code or expression exception.
